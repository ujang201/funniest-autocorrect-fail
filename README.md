## Entry

> Mom, I'm finally pregnant! I mean PRESENT. I'm finally present. At dinner. Please stop crying and tell Dad to get up.

## How it works

`main.ts` assembles the line from fixed parts and writes it to `/output/entry.txt`. The output is fully deterministic: no randomness, no clock, no environment reads, no network. Run it with `node main.ts` (Node 22+).
